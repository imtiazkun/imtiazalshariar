Checkout [Siteflow](https://www.siteflow.kone.com)

Siteflow is this software used on construction sites to manage lifts, i.e. see if they are operational, how many people are in it, on which floor, if something malfunctioned, etc. All this info properly baked in the UI.

The stakeholders thought it would be nice to be able to see these in a 3D environment and for that they needed someone who knew WebGL.

![Siteflow 3D Simulation 1](/assets/articles/siteflow-realtime-construction-3d-simulation/kone_siteflow_3d_1.jpg)

It started out simple just showing a simple representation of a building with no lifts or anything. Just plain webgl code running inside a VueJS codebase. Once, the idea solidified into something they wanted things moved forward and eventually implemented another basic version showing liftings moving based on real-time data.

![Siteflow 3D Simulation 2](/assets/articles/siteflow-realtime-construction-3d-simulation/kone_siteflow_3d_2.jpg)

Now, this feature has developed into something more useful and complicated unlike the screenshots presented of the priliminary stages of this feature.
